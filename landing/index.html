01 / REAL WORKFLOW真实界面 · 真实操作

一个顶部工作区，
接住 AI 协作中的零碎上下文。

SKILL LIBRARY

从一个入口查找所有 Skill

统一检索本地、系统、项目和插件提供的 Skill，同时查看分类、健康状态、来源与源码摘要。

02 / PRODUCT SYSTEM为频繁切换上下文的人设计

少一点找文件和复制路径，
多一点真正的工作。

INDEX

把分散的 Skill 汇总成可搜索的本地目录

索引 Codex Skill 根目录、系统 Skill、项目 Skill 和插件内容，并标注来源、重复项与健康状态。

HANDOFF

为每个聊天工具复制正确格式

选择 Codex mention、Claude prompt、ChatGPT prompt、Cursor prompt、纯文本或自定义模板，不再手工拼路径。

CONTEXT

在当前任务附近保留临时上下文

用 Markdown 快速记录思路，把待分析或待上传文件拖入暂存区，完成后再拖回下一步工作流。

LOCAL

本地优先，不把工作材料送往额外服务

Skill 索引、笔记、模板与文件暂存都围绕本机工作流构建，让开发资料留在自己的 Mac 上。

03 / FROM SEARCH TO HANDOFF

从“我记得有个 Skill”，
到把正确引用交给 AI。

  1. 01打开刘海工作区

    从菜单栏或主窗口进入，不离开当前任务。

  2. 02搜索并确认来源

    按名称、描述、标签、平台或路径筛选。

  3. 03补充笔记或文件

    把交接需要的临时上下文放在附近。

  4. 04复制到当前聊天

    选择目标平台模板，粘贴后继续工作。

05 / FAQ

常见问题

Skill Manager 会上传我的 Skill、笔记或文件吗？+

不会。产品采用本地优先设计，Skill 索引、临时笔记、复制模板和文件暂存工作流都在 Mac 本地完成。

它支持哪些 AI 工具？+

内置 Codex、Claude、ChatGPT、Cursor、纯文本和自定义模板，可针对不同聊天工具复制合适的 mention 或 prompt。

现在可以怎样安装？+

当前项目开放源码，可从 GitHub 克隆后使用 Xcode 构建，也可以运行仓库内脚本制作本地 DMG。

它是完整的 Skill 编辑器或 marketplace 吗？+

不是。当前重点是本地 Skill 的查找、来源确认、聊天交接，以及任务附近的笔记与文件暂存。
